FullStory
··

Give it one or more ApplicationIDs and it finds each one's FullStory sessions from the last 90 days and records them to video, one batch per job. This opens a real Chrome window on this machine and can take a while -- only one recording job runs at a time.

A file and the pasted list can be combined -- ids are deduplicated. A file can be a JSON array, a JSON object (its values are used), or a plain list with one id per line.
